     * Parte 3 — Pregunta de Reflexión
     * La Pila es ideal porque sigue el principio LIFO (Last-In, First-Out), permitiendo acceso 
     * inmediato al evento más reciente sin recorrer toda la estructura[cite: 12, 21].
     * Una lista normal por índice obligaría a gestionar manualmente el puntero del final; 
     * si se accede por el inicio (índice 0) en una lista simple, desplazar los elementos 
     * sería ineficiente comparado con el salto directo del tope de la pila.
