# Parte 3 — Pregunta de Reflexión
 * La Pila es ideal porque sigue el principio LIFO (Last-In, First-Out), permitiendo acceso inmediato al evento más reciente sin recorrer toda la estructura.
 * Una lista normal por índice tendría que manualmente configurar el indicador para estar siempre al final; si ingresamos por el índice 0 (el inicio de la lista) tendríamos que recorrerla toda y desplazar elemento por elemento para poder llegar al "tope".
